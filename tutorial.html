SFS Pack Tool 使用教程

SFS Pack Tool V2.3.1 · 汉化 / Prefab 导出 / 贴图 / Unity 工程导出 · 作者 A Future star

① 准备工作 / Before you start

  • 准备你的 mod.pack（AssetRipper 导出的原始素材包）。
  • 准备一份官方 Modding Toolkit 工程（含 Assets/Scripts）。
  • Prepare your mod.pack and an official Modding Toolkit project (must contain Assets/Scripts).

② 汉化文本 / Localization

  1. 1在「输入文件」区点 选择原始 mod.pack。
  2. 2点 提取待翻译文本，得到 texts_to_translate.json。
  3. 3翻译该 JSON 后，点 选择翻译 JSON，再点 写入汉化并生成 Pack。
  4. Pick the source pack, extract translatable text, translate the JSON, then write it back to produce a localized pack.

③ 一键导出 Unity 工程 / One-click Unity export

  1. 1点 选择工程目录（合并按钮）：先选 Modding Toolkit 根目录，再选 原始 mod 工程目录（可选，用于按名修复悬空引用）。
  2. 2勾选「导出后并入 Toolkit」（可选，默认只生成合并包、不覆盖既有文件）。
  3. 3点 一键导出工程。工具会：反编译 prefab → 免挂对齐脚本 → 修复空壳着色器（黑板根因）→ 生成合并包 → 自动清理 Toolkit 空壳着色器与悬空引用 → 导出后自检。
  4. One button now also runs the Toolkit stub-shader & dangling-reference repair, so black parts are fixed automatically.

关于「空壳着色器 / 悬空引用」

  • 空壳着色器：AssetRipper 把 SFS 自定义着色器反编译成不透明占位版，零件会被渲成一整块黑板（且不报错）。工具按 Shader 名换成 Toolkit 真源码。
  • 悬空引用：部件引用了 Toolkit 里不存在的 GUID（常见于火焰/贴图/音效材质），表现为 Odin 一片 Missing，渲染脚本取不到材质直接 NRE。提供原始 mod 工程目录可自动补入/重定向。
  • Stub shaders render parts as a black board; dangling refs cause Missing materials & NREs. Both are auto-fixed during export.

④ 合并包 / Merge package

  • 合并包只裁剪 Toolkit 没有 的新内容，归一化到 Assets/Resources/Parts/<模组名>/。
  • 已存在同名部件自动跳过；GUID 冲突会列出并取消写入，请按 MERGE_README.md 人工核对。
  • The merge package only adds what the Toolkit lacks; collisions are refused with a manifest.

⑤ 剥离 / Strip

  • 点 包信息 查看包含哪些平台与部件，再点 剥离到目标平台 大幅减小 .pack 体积。
  • Use Pack info then Strip to a target platform to shrink the .pack.
